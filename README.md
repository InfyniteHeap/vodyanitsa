# Vodyanitsa

> _「旅行者，要全神贯注听沃唱歌哦，不然沃就哭给你看::>\_<::」_

A high-performance music player written in pure Zig.

## Build from source code

All you need is to install a latest Zig toolchain. Follow Zig's [download documentation](https://ziglang.org/download/) to do so. Once installed, run this command in your command line to check whether you've properly installed Zig:

```bash
zig version
```

Clone source code:

```bash
git clone https://github.com/InfyniteHeap/vodyanitsa.git
```

Then build it:

```bash
cd vodyanitsa
zig build
```
